HTML va CSS Topshiriq

Ushbu topshiriqda class va id yordamida turli elementlarni uslublashni o'rganamiz.


Bo'lim 1:HTML haqida

HTML(HyprTex Markup Language) veb-sahifalarni yaratish uchun asosiy til hisoblanadi. HTML teglar yordamida veb-sahifalarning tuzilmasini aniqlash mumkun.

  • HTML teglar tuzilma yaratadi.
  • HTML odiy va qulay til
  • Har bir elamentlarni o'ziga hos vazifasi bor

Bo'lim 2: CSS haqida

CSS (Cascading Style Sheets) veb-sahifalarni usliblash uchun ishlatiladi. U matn ranglar, shriftlar, orqa fon va boshqa dizayn elementlarni boshharadi

  1. CSS tashqi ko'rinishni boshqaradi.
  2. Inline, Ichki va tashqi uslub usulari mavjud.
  3. Responsiv dizayn ushun muhum.

Bo'lim 3: HTML va CSS birgalikta

HTML va CSS birgalikta ishlatilganda, veb-sahifalar chiroyli va interoktiv bo'ladi. HTML tarkibini aniqlaydi, CSS esa dizayini boshharadi.
